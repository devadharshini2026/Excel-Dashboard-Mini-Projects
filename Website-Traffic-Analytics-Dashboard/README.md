# Website / Traffic Analytics Dashboard

## **Project Overview**
This Excel dashboard tracks website traffic metrics for a fictional website. It analyzes **visitors, sessions, page views, bounce rate, and conversion metrics**, providing insights into user behavior and website performance.  

The goal of this project is to demonstrate **Excel skills in web analytics, data visualization, and interactive reporting**, suitable for data analyst or business intelligence roles.

---

## **Dataset**
- Sample dataset contains 50–100 rows with the following columns:  
  - `Date` – Date of website traffic  
  - `Page` – Page URL or Page Name  
  - `Visitors` – Number of unique visitors  
  - `Sessions` – Total number of sessions  
  - `PageViews` – Total page views  
  - `BounceRate` – Percentage of users who left after viewing one page  
  - `Conversions` – Number of goal completions (sign-ups, purchases)  

> Dataset can be generated for practice in Excel and used to create dynamic dashboards.

---

## **Key Skills & Concepts Demonstrated**
- **Formulas:** SUMIFS, AVERAGEIFS, Conversion Rate (`Conversions / Visitors`)  
- **PivotTables:** Aggregate metrics by page, date, or traffic source  
- **PivotCharts:** Line chart for traffic trends, Bar chart for top pages  
- **Conditional Formatting:** Highlight pages with high bounce rate or low conversions  
- **KPI Cards:** Total Visitors, Total Sessions, Total PageViews, Total Conversions, Average Bounce Rate  
- **Slicers & Filters:** Filter by Page, Date, or Traffic Source  

---

## **Dashboard Features**
1. **Traffic Trend:** Line chart showing daily/weekly visitors and sessions  
2. **Top Pages:** Bar chart highlighting the pages with the highest views or conversions  
3. **Conversion Metrics:** KPI cards for total conversions and conversion rate  
4. **Bounce Rate Analysis:** Conditional formatting to highlight pages with high bounce  
5. **Interactive Slicers:** Filter by Page or Date to analyze traffic dynamically  
6. **Segment Comparison:** Optional: Compare traffic sources (Organic, Paid, Referral)  

---

## **How to Use**
1. Download `Website_Traffic_Analytics_Dashboard.xlsx`.  
2. Open in **Microsoft Excel (2016 or later)**.  
3. Use slicers to filter by Page or Date dynamically.  
4. Explore PivotTables, charts, KPI cards, and conditional formatting for insights.
