# Project Management Dashboard

## **Project Overview**
This Excel dashboard helps track project tasks, progress, and deadlines. It monitors **task completion, status, assignees, and deadlines**, providing interactive insights into project performance and bottlenecks.  

The goal of this project is to demonstrate **Excel skills in project management analytics, visualization, and interactive reporting**, useful for project management or data analyst roles.

---

## **Dataset**
- Columns included:  
  - `TaskID` – Unique identifier for each task  
  - `TaskName` – Name or description of the task  
  - `Assignee` – Person responsible for the task  
  - `Status` – Current status (e.g., Not Started, In Progress, Completed)  
  - `StartDate` – Task start date  
  - `EndDate` – Task end date  
  - `Completion%` – Percentage of task completed  

> The dataset contains 50 sample tasks created for portfolio purposes.

---

## **Key Skills & Concepts Demonstrated**
- **Formulas:** Progress calculation (`Completion%`), conditional alerts  
- **PivotTables:** Aggregate tasks by assignee, status, or project phase  
- **PivotCharts:** Visualize task distribution, progress, and completion trends  
- **Gantt Charts:** Track task timelines using conditional formatting  
- **Conditional Formatting:** Highlight overdue tasks or delayed milestones  
- **KPI Cards:** Total Tasks, Completed Tasks, Tasks In Progress, Overdue Tasks  
- **Slicers & Filters:** Interactive filtering by Assignee or Status  

---

## **Dashboard Features**
1. **Task Status Overview:** Column chart showing task count by status  
2. **Task Distribution by Assignee:** Bar chart showing tasks assigned to each team member  
3. **Project Timeline (Gantt Chart):** Visual representation of task start and end dates  
4. **Completion Metrics:** KPI cards showing total tasks, completed, in progress, and overdue  
5. **Conditional Formatting:** Highlights tasks that are behind schedule  
6. **Interactive Slicers:** Filter tasks by Assignee or Status  

---

## **How to Use**
1. Download `Project_Management_Dashboard.xlsx`.  
2. Open in **Microsoft Excel (2016 or later)**.  
3. Use slicers to filter tasks by Assignee or Status dynamically.  
4. Explore PivotTables, charts, KPI cards, and Gantt charts for project insights.

This dashboard demonstrates practical **Excel skills** for project tracking and management analytics. It’s a **ready-to-show portfolio project** for freshers aiming for **data analyst, business intelligence, or project management roles**.
